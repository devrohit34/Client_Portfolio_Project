# Satish Rajput — School Impact Portfolio

A responsive React + Vite portfolio focused on school partnerships, Robotics & AI labs, STEM education, student achievement, workshops, and business growth.

## Run locally in VS Code

1. Extract the ZIP.
2. Open the `satish-rajput-school-impact-portfolio` folder in VS Code.
3. Install Node.js (LTS) if it is not already installed.
4. Open **Terminal → New Terminal** and run:

```bash
npm install
npm run dev
```

5. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Included features

- Responsive navigation and mobile menu
- Persistent dark/light theme toggle
- Animated hero and scroll reveal effects
- Impact metrics and revenue chart
- School partnership, work and press photo gallery
- Responsibilities cards and contact links
- Keyboard focus states and reduced-motion support

## Images

Your supplied images are in `public/images/`. The hero uses `satish-portrait.png`; gallery cards use the event and press photos. Replace files in this folder if you want to update photos, keeping the same filenames.

## Accuracy note

The 2022–2026 revenue values are shown as company-level figures supplied for this portfolio, not as revenue personally generated by one individual. Please verify figures, record counts, and wording before publishing.
